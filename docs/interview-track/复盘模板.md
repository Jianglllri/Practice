# 面试项目与模拟复盘模板

把模板复制到个人 Notess 笔记里填写。项目讲述采用可公开的场景、指标口径和验证过程。练习示例用合成数据，效果可以写成可验证的假设。

## 项目口述

1. 30 秒说明用户、场景、失败代价和目标。
2. 60 秒说明旧方案、数据口径、可见时点和基线。
3. 90 秒说明你的职责、核心设计、为什么选这个方案，以及最重要的取舍。
4. 60 秒说明消融、对照、线上护栏、观察窗口和误差来源。
5. 60 秒说明一次失败、如何诊断、怎样回退，以及下一轮实验。

追问自己三个问题。换掉关键模型会发生什么？效果如何排除流量或样本结构变化？数据、工具或政策变动后如何发现回归？

## 模拟面试

- 日期、投递方向、题目链接和独立完成用时
- 算法失分点。思路、边界、实现、复杂度或验证
- 八股失分点。写下遗漏的条件、反例和业务影响
- 项目失分点。记录讲不清的个人贡献、基线、归因或护栏
- 下一次复测。指定一道同类新题、一道口述题和重练日期
